# MediaFlux App — Complete Development Journey

## 1. Project Overview

### App Name

MediaFlux

### Purpose

MediaFlux is an adaptive media optimization application built using Flutter. The app allows users to:

* Upload images
* Optimize/compress them
* Convert them into modern formats like WEBP and AVIF
* Compare original vs optimized media
* Download optimized media directly to device storage

The application was designed with a premium dark UI and modern optimization workflow.

# 5. Major Issues Faced + Solutions

## ISSUE 1 — before_after slider not working

### Problem

The comparison slider package was not behaving correctly.
Slider thumb was visible but dragging did not work.

### Errors Faced

```dart
No named parameter with the name 'moveLeftThumbOnDrag'
```

### Root Cause

Package version mismatch and unsupported parameters.

### Final Resolution

Completely removed draggable slider approach.
Replaced with:

* Original image card
* Optimized image card

This became the final UI.

---

## ISSUE 2 — Huge Empty Space in Result Cards

### Problem

Cards contained excessive vertical spacing.

### Root Cause

Fixed container heights and spacing widgets.

### Resolution

* Reduced container height
* Reduced padding
* Adjusted SizedBox values
* Better image scaling

---

## ISSUE 3 — Flutter WidgetStateProperty Error

### Error

```dart
The argument type 'Color' can't be assigned to the parameter type 'WidgetStateProperty<Color?>?'
```

### Root Cause

New Flutter API requiring WidgetStateProperty.

### Resolution

Changed:

```dart
Colors.deepPurple.withOpacity(0.2)
```

into:

```dart
WidgetStateProperty.all(...)
```

where required.

---

## ISSUE 4 — boxShadow syntax errors

### Errors

```dart
Expected ')' before this.
The getter 'boxShadow' isn't defined
```

### Root Cause

Incorrect decoration syntax.

### Wrong

```dart
 decoration: boxShadow: [
```

### Correct

```dart
 decoration: BoxDecoration(
   boxShadow: [
```

## ISSUE 6 — Replit Deployment Understanding

### Initial Confusion

Backend preview was working but public URL confusion existed.

### Working URL Example

```txt
https://appbackendmediaflux--piyushsharma171.replit.app
```

### Important Discovery

Preview URL and deployment URL are different.
Only deployment URL should be used inside Flutter app.

---

## ISSUE 7 — APK worked with USB but not standalone

### Problem

App worked while connected through:

```bash
flutter run
```

But failed after APK installation.

### Error

```txt
SocketException: Failed host lookup
```

### Root Cause

Release APK did not have INTERNET permission.

### Final Resolution

Added this inside AndroidManifest.xml:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

Then rebuilt release APK.

---

## ISSUE 8 — Missing Flutter Packages

### Errors

```txt
Couldn't resolve the package 'dio'
Couldn't resolve the package 'path_provider'
Couldn't resolve the package 'permission_handler'
```

### Root Cause

Dependencies missing from pubspec.yaml.

### Resolution

Added:

```yaml
dio: ^5.9.0
path_provider: ^2.1.5
permission_handler: ^12.0.1
```

Then:

```bash
flutter pub get
```

---

## ISSUE 9 — Download Button Opening Chrome

### Problem

Instead of downloading file, browser opened.

### Root Cause

Using URL launcher instead of actual file download.

### Final Resolution

Implemented proper download system using:

* Dio
* File storage
* Path provider
* Permission handler

---

## ISSUE 10 — Downloaded File Not Visible

### Problem

App showed:

```txt
Downloaded successfully
```

But file could not be found.

### Root Cause

Saving into inaccessible app-specific directory.

### Resolution

Used accessible external storage path.

---

## ISSUE 11 — MissingPluginException

### Error

```txt
MissingPluginException(No implementation found for method requestAccess)
```

### Root Cause

Hot reload/hot restart after plugin installation.

### Final Resolution

Completely stopped app.
Ran:

```bash
flutter clean
flutter pub get
flutter run
```
